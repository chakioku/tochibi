# お問い合わせフォーム 設置手順

`/contact` のフォームは、Google Apps Script（GAS）のウェブアプリに送信します。
静的サイトなのでサーバー側の処理を持てず、GASが受け口を担います。

送信されると次の3つが動きます。

1. スプレッドシートに1行記録
2. 学校の担当者宛に通知メール
3. 送信者宛に受付内容の控えを自動返信

---

## 1. スプレッドシートを作る

1. Googleドライブで新しいスプレッドシートを作成します
2. 名前を「栃美OCサイト お問い合わせ」など分かりやすいものにします
3. シートは空のままで構いません。初回送信時に見出し行が自動作成されます

**作成するアカウント**に注意してください。通知メールはこのアカウントから送信されるため、学校の管理用アカウントで作成することをおすすめします。個人アカウントで作ると、担当者が変わったときに引き継げません。

## 2. スクリプトを貼り付ける

1. スプレッドシートのメニューから **拡張機能 → Apps Script** を開きます
2. 既存の `function myFunction() {}` を全て削除します
3. `docs/contact-form.gs` の中身を全てコピーして貼り付けます
4. 冒頭の設定を確認します

```js
var NOTIFY_TO = 'info@tochibi.ac.jp';   // 通知メールの宛先
var SENDER_NAME = '栃木県美容専門学校';
var SHEET_NAME = 'お問い合わせ';
var ALLOWED_ORIGINS = ['https://tochibi-oc-vercel.vercel.app'];
```

**本番ドメインが決まったら `ALLOWED_ORIGINS` に追加してください。** ここに載っていないURLからの送信は拒否されます。

5. 保存します（Ctrl+S / Cmd+S）

## 3. 動作テスト

デプロイの前に、スクリプト単体で動くか確認します。

1. エディタ上部の関数選択で **`testRun`** を選び、**実行** を押します
2. 初回は権限の確認が出ます。「詳細」→「（プロジェクト名）に移動」→「許可」と進みます
3. スプレッドシートに1行増えていること、自分宛にメールが2通届くことを確認します

ここで失敗する場合は、デプロイしても動きません。エラー内容を確認してください。

## 4. ウェブアプリとしてデプロイ

1. 右上の **デプロイ → 新しいデプロイ** を押します
2. 歯車アイコンから **ウェブアプリ** を選びます
3. 設定を次のようにします

| 項目 | 値 |
|---|---|
| 説明 | 栃美OCサイト お問い合わせフォーム |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

「アクセスできるユーザー: 全員」は必須です。ここが「自分のみ」だと、サイトからの送信が全て失敗します。フォームの内容自体は誰にも見えないので、この設定で問題ありません。

4. **デプロイ** を押し、表示される **ウェブアプリのURL** をコピーします

```
https://script.google.com/macros/s/AKfycb.../exec
```

## 5. サイト側にURLを設定

`assets/js/oc.js` を開き、`GAS_ENDPOINT` にURLを貼り付けます。

```js
var GAS_ENDPOINT = "";
        ↓
var GAS_ENDPOINT = "https://script.google.com/macros/s/AKfycb.../exec";
```

保存してコミット・プッシュすれば反映されます。

## 6. 本番での確認

デプロイ後、実際に `/contact` から自分宛に1件送信して、次を確認してください。

- 確認画面に入力内容が正しく出るか
- 送信後に完了画面が出るか
- スプレッドシートに記録されるか
- 担当者宛の通知メールが届くか
- 送信者宛の自動返信が届くか（**迷惑メールフォルダも確認**）

---

## スクリプトを修正したとき

コードを変更しただけでは本番に反映されません。**デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ** の操作が必要です。

新規デプロイを作り直すとURLが変わってしまうので、必ず既存のデプロイを編集してください。

---

## 注意点

**送信数の上限があります。** 無料のGoogleアカウントでは、GASから送れるメールは1日100通までです。1件の送信で2通（通知＋自動返信）使うので、実質1日50件が上限です。通常のお問い合わせ量なら問題ありませんが、オープンキャンパス直前などに集中する場合はご注意ください。Google Workspaceアカウントなら1日1,500通です。

**自動返信の差出人は、スクリプトを作成したGoogleアカウントのアドレスになります。** `info@tochibi.ac.jp` から送りたい場合は、そのアドレスでログインしてスプレッドシートを作成するか、Gmailの「送信元アドレスの追加」設定が必要です。フォームの案内文で「tochibi.ac.jp のドメインからのメールを受け取れるように」と書いているので、ここは揃えておくのが望ましいです。

**スパム対策は2段構えです。** 人には見えない入力欄（ハニーポット）と、ページを開いてから3秒未満の送信を弾く仕組みが入っています。それでも迷惑送信が増える場合は、reCAPTCHAの導入をご検討ください。

**個人情報の取り扱い**について。スプレッドシートには氏名・メールアドレス・相談内容が蓄積されます。閲覧できる人を必要最小限に制限し、共有リンクを「リンクを知っている全員」にしないでください。また、対応済みの古いデータをいつ削除するかも決めておくことをおすすめします。

## うまく動かないとき

| 症状 | 確認すること |
|---|---|
| 「送信先が未設定です」と出る | `oc.js` の `GAS_ENDPOINT` が空 |
| 「送信に失敗しました」と出る | デプロイの「アクセスできるユーザー」が「全員」か。URLの末尾が `/exec` か（`/dev` は不可） |
| 送信は成功するが記録されない | `SHEET_NAME` とシート名が一致しているか |
| メールが届かない | 迷惑メールフォルダ。1日の送信上限に達していないか |
| 特定の環境からだけ失敗する | `ALLOWED_ORIGINS` に本番ドメインが入っているか |
